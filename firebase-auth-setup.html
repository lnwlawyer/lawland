LawLand — ทดสอบเข้าสู่ระบบ Firebase ใหม่

หน้านี้เชื่อมต่อเฉพาะ Firebase Project land-law-ea2bb เพื่อสร้างบัญชี Google ครั้งแรก โดยไม่เปลี่ยนระบบเข้าสู่ระบบหลัก และไม่เขียนข้อมูลลง Firestore

ใช้บัญชี Google ที่ต้องการให้เป็น Admin เท่านั้น ตรวจสอบ URL ว่าอยู่บน lnwlawyer.github.io ก่อนเข้าสู่ระบบ อย่าส่งรหัสผ่านหรือ ID Token ให้ใคร

กำลังเตรียม Firebase…



หลังเข้าสู่ระบบสำเร็จ ให้เปิด Firebase Console → Authentication → Users ของโปรเจ็กต์ land-law-ea2bb เพื่อตรวจสอบบัญชี และส่งเฉพาะ UID กลับมาในแชท
