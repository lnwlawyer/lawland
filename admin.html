พื้นที่จัดการเอกสาร

ระบบตรวจสอบบทบาท Admin ผ่าน Firebase ID Token แล้ว แต่ยังไม่เปิดการเพิ่ม แก้ไข ตรวจสอบ อนุมัติ หรือเผยแพร่เอกสาร จนกว่าจะมี API ฝั่งเซิร์ฟเวอร์ที่ตรวจสอบสิทธิ์และบันทึกประวัติได้

สถานะงานเอกสารที่วางแผน: ฉบับร่าง → รอตรวจสอบ → อนุมัติ → เผยแพร่ หรือส่งกลับแก้ไข
